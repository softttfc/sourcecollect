# AGENTS.md — Contributor Guide (tvbox)

A **TVBox-style aggregation data-source repo** (a fork of `cluntop/tvbox`, deployed at `https://clun.top/`). The repo holds **config JSONs** that wire together many crawler backends — Python (`py/`), JavaScript/drpy (`js/`), and Java spider jars (`jar/`) — plus IPTV playlists (`lib/*.m3u`) and the scripts/CI that keep them updated. This is a data/config repository, **not** a single application: there is no package, build step, or test suite. Most work here is editing one crawler file, then adding/referencing it in a top-level config JSON.

Note: `AGENTS.md` files already exist for the sibling projects under `/workspace` (`clun-test/AGENTS.md`, and `deepseek-harness-example/` is config-only). This file covers the `tvbox/` repo only.

## Repository layout

| Path | Purpose |
|---|---|
| `box.json`, `fun.json`, `jsm.json`, `aa.json`, `bb.json`, `wv.json`, `test.json` | Top-level **TVBox config files**. Each is a dict of `sites`, `lives`, `doh`, `proxy`, `parses`, `flags`, `spider`, `headers`, `rules`, `wallpaper`. `box.json` is the primary "self-use" config (`https://clun.top/box.json`); `fun.json` is the collection/aggregation config; `jsm.json` is the PG jar config (`spider = ./pg.jar`); `wv.json` uses `./jar/WvSpider.jar`. **Editing a crawler usually means editing its entry here.** |
| `py/*.py` | **Python crawlers** (Pyramid/dr_py lineage). ~130 files. Each is a standalone `class Spider(Spider)` file using `sys.path.append('..')` + `from base.spider import Spider`. Registered with `"type": 3, "api": "./py/<name>.py"`. |
| `js/*.js` | **drpy2/JS crawlers**. `js/*.js` (78 files) plus subdirs `js/s/` (config-JSON packs), `js/ss/`, `js/xiaosa/` (vendored from an upstream TVBoxOSC source by CI). Many are `var rule = {...}` drpy rules; some (e.g. `apple.js`) are async-function crawlers. Registered with `"api": "./js/<name>.js"`. |
| `jar/*.jar` + `*.md5` | Compiled Java spider jars (e.g. `WvSpider.jar`, `yt.jar`); `pg.jar` sits at repo root. `.md5` sidecars are regenerated by CI. |
| `lib/` | Static assets: IPTV `.m3u`/`.txt` playlists, crypto libs (`cheerio.min.js`, `crypto-js.js`, `node-rsa.js`), and JSON data packs (`bilibili.json`, `alistjar.example.json`, `sources.json`, etc.). |
| `py/get_iptv.py` | Maintains the IPTV `.m3u`/`.txt` files (fetches+dedupes sources); run by the `tv.yml` workflow. |
| `py/sync-pg.py` | Pulls PG assets and commits (uses `PHONE`/`API_ID`/`API_HASH`/`GIT_TOKEN` env; note it reads them from `os.environ`). |
| `git.sh` | Manual Git CLI helper for Termux/MT-manager on Android. Commits to this repo; not a build tool. |
| `index.html`, `img/`, `js/index*.js`, `js/index.css` | Static landing page for `https://clun.top/` (not the TVBox configs). |
| `_headers` / `_redirects` | Cloudflare Pages header rules (long browser cache for `*.json/*.jar/*.js/*.py/*.txt`). |

## Config JSON structure

Each site entry in a config's `sites` array keys on `"type"`:

- `"type": 1` — collection/CMS API source (`"api": "…/api.php/provide/vod/"`, `"ext": "proxy"`).
- `"type": 2` — settings/WebView source (see `wv.json`).
- `"type": 3` — spider source: `"api"` points to `./py/<name>.py`, `./js/<name>.js`, or a `csp_<Class>` name resolved by a jar (e.g. `csp_Douban`, `csp_ProxySpider`). Optional `searchable`, `quickSearch`, `filterable`, `changeable`, `ext` (extra config/headers).

The `spider` key at top level selects the default jar (e.g. `./pg.jar`, `./jar/yt.jar`). When you add a crawler, mirror an existing equivalent entry and make sure the referenced `api` path is correct.

## Build / run / lint / test

- **No build, no package manager, no linter, no automated test suite.** The `.github/requirements.txt` is only for CI scripts (`GitPython`, `Telethon`, `requests`, `demoji`, `tqdm`, `aiohttp`).
- **Validate JSON configs** after editing any `*.json`: `python3 -m json.tool box.json` (a common failure is a trailing comma or an unescaped path).
- **Check a Python crawler imports** (it needs the `base` package at runtime, which the jar provides — it is **not** vendored in this repo, so a standalone `python3 py/foo.py` will fail on `from base.spider import Spider` unless you add a base path). Quick syntax check: `python3 -m py_compile py/<name>.py`.
- **drpy JS rules** have no local runner; verify by linting mentally against the `rule = {...}` shape and existing working rules. `.md5` files are CI-maintained — do **not** hand-edit them.
- **CI workflows** (`.github/workflows/`): `md5.yml` regenerates `*.md5` on pushes to `**.js`/`**.jar`; `tv.yml` runs `py/get_iptv.py`; `zip.yml` vendors `js/xiaosa/` from upstream; `sync.yml` force-syncs the fork from upstream (`discard` strategy by default); `static.yml` deploys the Pages site; `clear.yml` prunes git garbage. Note many commit/push steps are partially commented out and use a `GIT_TOKEN` secret.

## Coding conventions

- **Encoding:** `.editorconfig` requires `utf-8`, `lf`, space indent, `indent_size = 2` generally but `4` for `*.py`. Use 4-space for new `.py`, match the file you edit otherwise.
- **Python crawlers:** header `# -*- coding: utf-8 -*-` + optional `# by @<author>`; `import sys; sys.path.append('..')`; `from base.spider import Spider`. Override `init(extend)`, `homeContent(filter)`, `homeVideoContent`, `categoryContent(tid, pg, filter, extend)`, `detailContent(ids)`, `searchContent(key, quick)`, `playerContent(flag, id, vipFlags)`, and stub `isVideoFormat`/`manualVideoCheck`/`destroy`/`getName`. Return shapes are the standard TVBox dicts (`{"class":[...],"list":[...]}`, `{"page":int,"pagecount":int,"limit":int,"list":[...]}`, `{"list":[vod]}`, `{"list":[...],"page":int}`, `{"parse":0,"url":"http(s)…","header":{...}}`). Keep the standard `vod_*` keys.
- **JS drpy rules:** prefer the compact `var rule = { title, host, url, searchUrl, class_name, class_url, 一级, 二级, 搜索, play_parse, lazy, headers, timeout }` shape with `pdfh`/`pdfa`/`pd`/`jsp` helpers and `js:` blocks. Use local-proxy URLs like `http://127.0.0.1:9978/proxy?do=ali&type=push&url=…` for cloud-drive links.
- **Headers/UA:** set `User-Agent` (often `okhttp/…` or `PC_UA`); add `Referer` and `Cookie` when a site returns 403. Local-proxy cookie via `http://127.0.0.1:9978/file:///tvbox/JS/lib/<file>.txt`.
- **Error tolerance:** external live sites rot; wrap extraction defensively, keep timeouts bounded, and re-analyze a page before "fixing" a crawler. Don't hammer targets while developing.

## Important setup / gotchas

- `py/` files import `base.spider`, which is **provided by the runtime jar, not this repo** — there is no `base/` directory here. Don't create one; don't expect standalone execution.
- `py/sync-pg.py` and `py/get_iptv.py` read credentials/network config from environment variables and are intended for CI, not local ad-hoc use.
- When editing a top-level config, add/remove the site entry in the **right** config — `box.json` (self-use), `fun.json` (aggregation), `jsm.json` (PG), `aa.json`/`bb.json` (other channels). Verify the target `api`/`spider` jar actually provides the referenced class.
- Never commit `.md5` files by hand; they are CI-generated to match content hashes.
